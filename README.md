# Aditi Sonawane — Technical Portfolio & Interactive RCA Playground

Personal portfolio and interactive engineering simulator for **Aditi Sonawane**, Technical Product Engineer & Enterprise Integration Specialist. Hosted live on GitHub Pages at [aditisonawane650.github.io](https://aditisonawane650.github.io/).

---

## 🚀 Overview

This website highlights 5+ years of experience in enterprise B2B SaaS, cloud infrastructure, and ERP/CRM/e-commerce connector ecosystems (SAP, Oracle, NetSuite, Salesforce CPQ, Shopify, WooCommerce).

### Key Highlights
- **Interactive RCA Playground**: A live simulator showcasing Tier-2/Tier-3 triage workflows, API payload forensics, simulated SQL/log analysis, and engineering escalation UAT processes.
- **Enterprise Connector Ecosystem**: Overview of integrations across ERP, CRM, and cloud platforms.
- **8-Pillar Competency Matrix**: Filterable grid covering Incident Governance, Cloud/APIs, Systems & Forensics, Security, ITSM, and Client Enablement.
- **Career Progression**: Detailed timeline of technical roles and milestones.
- **Dark / Light Theme Toggle**: Persistent custom CSS theme switcher.

---

## 🛠️ Tech Stack

Built deliberately without heavy frameworks or build tools for lightning-fast load times and zero dependency overhead:

- **HTML5**: Semantic markup, accessible navigation, and SEO meta tags.
- **CSS3**: Custom properties (CSS variables), Flexbox, CSS Grid, smooth transitions, and responsive typography without utility libraries.
- **JavaScript (ES6+)**: Vanilla JS powering the RCA simulator tab switching, theme toggling, interactive category filtering, and scroll reveal animations.

## 💻 Local Development

No package installation or build step is required. You can preview the site locally using any static file server:

### Option 1: Python HTTP Server
```bash
# Python 3
python3 -m http.server 8000
```
Then open [http://localhost:8000](http://localhost:8000) in your browser.

### Option 2: Node.js (npx)
```bash
npx serve .
```

### Option 3: VS Code Live Server
Right-click on [`index.html`](index.html) and select **"Open with Live Server"**.

---

## 🌐 Deployment

The site is configured for static hosting directly via GitHub Pages:

1. Push commits to the `main` branch.
2. In the repository settings on GitHub, navigate to **Pages**.
3. Under **Build and deployment**, select **Source: Deploy from a branch** and set the branch to `main` / `/ (root)`.
4. The site will publish automatically to `https://<username>.github.io/`.
